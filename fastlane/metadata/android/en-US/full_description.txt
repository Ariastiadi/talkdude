talkdude is a free, private AI chat companion. No account and no chat limits.

<b>On-device AI, no key needed</b>
Download a small open model once (Qwen 3.5, Qwen 2.5 or Llama 3.2) and chat as much as you like, even offline. Qwen 3.5 can also look at your photos.

<b>Or bring your own AI</b>
Google Gemini, Claude, OpenAI, Groq, OpenRouter's free models, DeepSeek, Mistral, Ollama or any OpenAI-compatible server.

<b>Features</b>
• Memory like the big chat apps: say "save to memory", see and edit everything it learned, Undo any save
• Talk instead of typing (Whisper runs on your phone), hear answers read aloud, or use hands-free voice chat with the camera
• Attach pictures, PDF, Word, text and code files to any AI
• Web search and link reading for every AI, no key needed
• Think mode and a Run button for JavaScript and Python code
• Create your own chat characters (Character Card V2 import/export)
• Swipes, reply editing, pinned memories and personas for role-play
• Export chats, back up and restore everything
• Black and white Nothing-inspired design, dark or light

<b>Private</b>
Chats are stored only on your device. No ads, no trackers. Open source (GPL-3.0).
